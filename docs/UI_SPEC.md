# UI/交互规格（UI / Interaction Specification）

> 信息架构与页面骨架已在头脑风暴第五节获用户确认；本文件细化到实现级。

## 页面

### 页面：令牌门（TokenGate）
用途：输入访问令牌验证身份。
入口：任何未认证访问。
出口：验证成功 → 上次访问页（默认启动台）。

### 页面：启动台（Home，默认路由）
用途：一键启停 ComfyUI、看状态、看日志。
入口：侧栏「启动 ComfyUI」。
出口：版本管理 / 打开 ComfyUI（新标签）。

### 页面：版本管理（Versions）
用途：浏览/安装/切换/删除 ComfyUI 版本。
入口：侧栏。

### 页面：插件管理（Plugins）
用途：插件列表、更新、启用/禁用。
入口：侧栏。

### 页面：工作流管理（Workflows）
用途：官方库导入 + 本地上传 + 已导入管理。
入口：侧栏。

### 页面：系统设置（Settings）
用途：令牌管理、面板更新、主题、自启、面板日志、安装自检重跑。
入口：侧栏。

### 启动台主区

```
+--------------------------------------------------------------+
| [▶ 启动 ComfyUI] [■ 停止] [↻ 重启]   ☑学术加速  [启动参数][打开 ComfyUI →] |
+--------------------------------------------------------------+
| [GPU 卡] [驱动卡] [显存卡] [进程状态卡]                        |
| [内存卡] [磁盘卡]                                              |
+--------------------------------------------------------------+
| 运行日志（等宽字体，自动滚动，ERROR 红色高亮，[暂停滚动][清屏][下载]） |
+--------------------------------------------------------------+
```

「启动参数」点开为抽屉（Drawer）：预设选择、端口、额外参数、保存（保存即校验）。
「打开 ComfyUI」仅在 state=running 时可点；指针悬停显示端口说明。

### 版本管理主区
顶部：「当前版本：v0.39.0」徽标 + [刷新索引]。
两段列表：「可用版本」（卡片：版本号/日期/体积/torch 基线/状态按钮 安装|切换|删除）、「已安装」。运行中时切换/删除按钮禁用并带提示 tooltip。

### 插件管理主区
卡片列表：名称/简介/版本提示/更新状态徽标 + [更新][禁用|启用]。无 git 远程的插件显示「本地安装」且更新按钮禁用。

### 工作流管理主区
Tab 1「官方库」：顶部 [刷新库]；卡片网格（封面图/名称/分类/更新时间/依赖徽标数）+ [导入]；已导入的显示「已导入 ✓」（仍可重导覆盖）。
Tab 2「我的工作流」：顶部 [上传 JSON]（拖拽区 + 点击）；列表：名称/来源/导入时间/依赖（N 缺失 红标）/ [查看依赖][删除]。

### 系统设置主区
分节卡片：访问令牌（[重新生成]，明文只显示一次弹窗）、面板更新（当前/最新/更新日志/[一键升级]，升级中显示 phase 进度条）、外观（主题单选）、开机自启（开关 + bashrc 说明）、面板日志（过滤 + [下载]）、安装自检（[重新自检] + 结果列表）。

### 栅格与断点
- 主区最大宽度 1280px；状态卡栅格 4 列（≥1280）/ 2 列（768-1279）/ 1 列（<768）。
- 断点：<1024 侧栏折叠为图标条（可展开）；<768 单列、页头保留。**桌面优先**（AutoDL 用户实操场景是 PC 浏览器），移动端保证可读可用不优化密度。

### 间距与密度
- 基准 4px；刻度 4/8/12/16/24/32。
- 卡片内边距 16px，卡间距 12px；信息密度中高（控制面板工具，避免过度留白），日志区除外（全宽）。
- 阅读顺序：启动台首屏必须先看到 [启动按钮+进程状态]，其次状态卡，再次日志。

## 用户交互

### UI-001 启动 ComfyUI
动作：点 [▶ 启动]。
结果：按钮变「启动中…」转圈；SSE 日志区开始滚动；进程卡 starting→running。
校验：后端校验版本已装/端口/参数；前端仅提交。
错误：Toast 显示 API error.message；日志区高亮失败原因。

### UI-002 停止/重启
动作：点 [■ 停止]/[↻ 重启]（运行中才可用）。
结果：状态 stopping；停止成功 Toast「已停止」。

### UI-003 切换版本
动作：版本卡 [切换]。
结果：ConfirmDialog「切换到 vX.Y.Z？模型与输出不受影响」→ 确认后调 API → 成功后侧栏版本号即时更新。

### UI-004 安装版本
动作：版本卡 [安装]。
结果：卡片进入进度态（ProgressInline 显示下载 %/速度）；完成后按钮变 [切换]。

### UI-005 更新插件 / 启用禁用
动作：插件卡按钮。
结果：更新中按钮转圈；失败在卡片下显示红色原因行（不弹窗）。

### UI-006 导入官方工作流
动作：库卡 [导入]。
结果：按钮转圈 → 成功 Toast「已导入，依赖模型 N 缺失 M」→ 卡片标「已导入 ✓」。

### UI-007 上传工作流
动作：拖拽或点击上传。
结果：前端校验 .json → 上传 → 失败（格式）显示原因；成功进入「我的工作流」列表。

### UI-008 重新生成令牌
动作：设置页 [重新生成]。
结果：ConfirmDialog 警示「所有已登录会话将失效」→ 弹窗一次性显示新令牌 + [复制] → 本地会话以新令牌续期。

### UI-009 一键升级面板
动作：设置页 [升级到 vX]。
结果：phase 进度条（下载→staging→切换）→ done Toast 提示页面将自动刷新；rolled_back 红色横幅含原因。

### UI-010 主题切换
动作：页头月亮/太阳。
结果：即时切换 + localStorage 持久化。

## 状态

每个列表页（版本/插件/工作流）必须实现：
- 加载中：骨架屏（卡片形状）
- 空状态：EmptyState（文案 + 引导动作，如「还没有安装任何版本 → 去安装」）
- 成功：正常渲染
- 错误：ErrorBanner（重试按钮），列表保留缓存数据置灰
- 禁用：守卫态（运行中切换等）tooltip 说明原因
- 进行中：按钮级转圈/进度条，禁止整页遮罩

日志区：连接中（半透明「连接中…」）/ 已断开（顶部黄条「日志连接断开，自动重连中」）。

## 响应式行为
- <1024：侧栏折叠图标条；状态卡 2 列。
- <768：状态卡 1 列；ActionBar 按钮换行；表格全部卡片化。
- 触屏：所有可点目标 ≥40×40px；无纯悬停信息（tooltip 信息同时可点开）。

## 无障碍
- 对比度 ≥ 4.5:1（正文）；焦点环 2px 可见；全键盘可达（侧栏/按钮/对话框 Tab 顺序）；状态不仅靠颜色（徽标带文字）。
- 图标按钮均有 aria-label。

## 性能预期
- 首屏（dist 本地加载）< 1s；页面切换无感（SPA）；状态轮询 5s、页面隐藏时暂停；日志 SSE 增量渲染上限 500 行 DOM（更旧的移除）。
